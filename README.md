Sistema de Agendamento Online

Projeto desenvolvido para gerenciamento de agendamentos de forma prática e organizada, permitindo controle de horários, clientes e serviços em tempo real.

Funcionalidades
Cadastro e login de usuários
Agendamento de horários
Gerenciamento de clientes
Painel administrativo
Controle de disponibilidade
Calendário de agendamentos
Cancelamento e confirmação de horários
Interface responsiva para desktop e mobile
Tecnologias utilizadas
React
TypeScript
Node.js
PostgreSQL
Objetivo do projeto

O objetivo do sistema é facilitar o gerenciamento de agendamentos para empresas e profissionais, oferecendo uma experiência moderna, rápida e intuitiva.
